# Lahore Garrison University Website

A React-based university website focused on LGU home and program routes.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Stack

- **React 18** + **Vite**
- **React Router** for routing
- **Modular component/page architecture**
- **Route-based page structure**

## Routes

- **Home** — Main LGU landing page
- **BSCS** — BS Computer Science route scaffold
- **BSSE** — BS Software Engineering route scaffold
- **BSAI** — BS Artificial Intelligence route scaffold
